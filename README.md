# Machine Learning 441 - Assignment 2

This repository contains the Jupyter notebook used for Assignment 2:
**Nearest Neighbours & Decision Trees**.

The analysis compares k-nearest neighbours (kNN) and a classification
decision tree on the provided modified UNSW-NB15 network traffic dataset.

The notebook includes:

- exploratory analysis of the remaining data-quality issues;
- model-specific preprocessing;
- hyperparameter tuning;
- stratified cross-validation;
- comparison using Macro F1 and accuracy;
- class-specific performance and confusion matrices.

## Files

- `assignment2.ipynb` - complete analysis and model evaluation
- `.gitignore` - excludes local/environment and dataset files

The dataset is not included in this repository.
